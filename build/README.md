# build resources — electron-builder buildResources dir

Branding assets (generated, do not hand-edit):

- `icon.ico` — Windows exe/installer/uninstaller icon, rounded aurora tile,
  entries 16–256 px. electron-builder embeds it; `window.ts` also loads it for
  the BrowserWindow icon (`resources/build/icon.ico` when packaged).
- `icon.png` — 512 px rounded tile (electron-builder fallback).

Regenerate from the source artwork in `Logo/`:

```
python scripts/make_brand_assets.py
```

Installer wizard art (NSIS MUI2, referenced by electron-builder.yml):

- `installer-sidebar.bmp` — 164x314 24-bit BMP for the welcome/finish pages:
  aurora V, wordmark, tagline.
- `uninstaller-sidebar.bmp` — dimmed variant; tells users projects are kept.
- `installer-header.bmp` — 150x57 header strip for the wizard's inner pages.
- `license.txt` — MIT license text shown on the installer license page
  (regenerated from the repo `LICENSE` so it cannot drift).

All of the above are regenerated by `python scripts/make_brand_assets.py`
alongside the icons.
